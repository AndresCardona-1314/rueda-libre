ROLES

Rol HTML: El rol que cumplirá html es el de generar la estructura base de la página web para que luego el navegador pueda traducir dicho lenguaje. Es decir acá se estrutura todo el encabezado y cuerpo de la pagina(s)

Rol CSS: El rol de CSS es pulir y darle una mejor apariencia a la pagina web. Es decir, elegir paleta de colores y tipo de letra.

Rol JavaScript: El rol de JavaScript es todo el código base de lo que queremos que suceda con cada acción que se ejecute dentro de la página.

Justificación creación de formulario:


Select: Se utilizo el select/option debido a que es el que mejor se adaptaba para la parte de la selección de la bicicleta, tipo de plan y ruta. Es más amigable con una lista desplegable.
Input: Se utilizo el input type="email" para generar una casilla que permita en ese campo solo datos que contengan la estructura estandar de una dirección de correo electrónico.
Input: Se utilizo el input type="date" para generar una casilla que solo permitiera datos tipo fecha. Generando así una ventana emergente tipo calendario que a su vez solo permite colocar fechas dentro de un rango específico.
